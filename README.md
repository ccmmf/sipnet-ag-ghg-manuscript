# SIPNET AG GHG Manuscript

This repository contains the working manuscript for SIPNET 2 agricultural
greenhouse gas model development.

## Repository Layout

- `manuscript.qmd`: main Quarto manuscript source.
- `references/references.bib`: bibliography used by the manuscript.
- `references/pdfs/`: local reference PDFs.
- `notes/`: manuscript notes and writing TODOs.

## Render

Render the manuscript with Quarto:

```sh
quarto render manuscript.qmd
```

Rendered outputs are local build artifacts and should only be committed when
explicitly needed for review or submission.
